# AI 초안 생성 조건

- 여행 기간: 시작일·종료일을 포함해 1~7일. 앱 캘린더와 서버 요청 검증에 동일하게 적용한다.
- 선택한 스타일 각각을 모든 일차에서 최소 한 장소에 반영한다. 스타일이 없으면 활동 종류를 제한하지 않는다.
- 식사 장소는 기본 일정으로 포함할 수 있다. 예를 들어 쇼핑만 선택하면 매일 쇼핑과 식사를 구성하며, 무관한 관광 활동은 제외한다.
- AI 응답의 `matchedStyles`를 카테고리·방문 시각과 함께 검사한다. 쇼핑은 쇼핑, 맛집은 식당, 자연은 자연, 문화는 문화, 액티비티는 체험, 카페는 카페에 대응한다. 힐링은 자연·카페·관광, 야경은 18시 이후 식당 이외 활동이어야 한다.
- 모든 날짜에 걸쳐 정규화한 장소 이름과 카카오 장소 ID 중복을 검사한다. 장소 대체 시에도 같은 카테고리와 스타일을 유지하고 원래 방문 시각을 사용한다.
- 지도 검색에서 중복·부적합으로 제외한 장소를 미확인 장소로 되살리지 않는다. 검색 결과가 전혀 없으면 미확인 장소 경고를 표시한다. 미확인 장소의 실제 동일성 및 AI가 작성한 설명의 사실성은 별도 확인이 필요하다.
- AI 응답 검증은 최대 2회, 지도 검색 후 조건 위반에 따른 전체 생성은 최대 2회로 제한한다. 최악의 경우 AI 요청은 총 4회이며 무한 재시도하지 않는다. 실패하면 새 초안을 반환하지 않으며 기존 초안 재생성에서도 기존 내용을 유지한다.
- 키가 없는 SAMPLE 모드는 고정 시연용 일정으로, 위 AI 스타일 보장의 대상이 아니다.

DB 스키마 변경은 없다. 기존 저장 여행을 자동으로 재생성하지 않는다.

검증: `ItineraryRulesTests`와 `TripGenerationRulesTests`는 실제 유료 API 호출 없이 일별 스타일 누락, 이름/ID 중복, 대체 장소, 기간 제한을 확인한다.
