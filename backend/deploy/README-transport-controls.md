# 교통편 선택 및 웹 접속 개선 (2026-11-25)

- 항공: 지도에서 고른 일반 출발 장소와 실제 탑승 공항을 구분한다. 카카오에서 위치가 확인된 국내 공항 중 직선거리로 가까운 2곳을 제시한다. 처음에는 공항 위치 조회를 병렬 수행하고, 이후 서버 메모리 캐시를 사용한다. 공항까지의 이동 시간·국내선 운항 여부를 보장하는 추천은 아니다.
- 직접 선택은 아래에 전체 공항 목록을 펼친다. 귀가 항공편 출발 희망 시각 기본값은 20:00이며 변경 가능하다.
- 시간표의 항목을 누른 뒤 상단 버튼의 ‘선택’을 눌러 확정한다. 확정 전 후보 선택은 저장하지 않는다.
- 기차의 직접 선택은 지도 대신 코레일 공식 KTX 시간표(2026-11-01 시행)에서 추출한 88개 역 목록을 사용한다. 새 정차역은 TrainStationRecommendationService의 CATALOG를 갱신해야 한다. 선택 시 카카오에서 실제 철도역 위치를 조회하며, 출구·지하철역은 제외한다.
- 가는 편 장소와 탑승·하차역을 선택하면 오는 편에 반대 방향을 기본 입력한다. 사용자가 별도로 변경한 오는 편은 덮어쓰지 않는다.
- 새 여행 만들기 헤더의 홈 버튼은 입력 화면을 종료하고 홈으로 이동한다. 생성 처리 중에는 표시하지 않는다.
- 초안의 우측 하단 새로고침 버튼은 최신 초안을 조회한다. 저장·이동·메모 수정 중에는 비활성화한다.
- 장소 링크는 정보 → 길찾기 → 전화 순서로 표시한다.

## 웹 서버

web-performance.py는 기존 HTTPS·API·공유 프록시 설정을 유지하면서 JavaScript 압축과 Expo 해시 파일의 immutable 캐시, index.html 재검증을 추가한다. 기존 파일을 백업하고 nginx -t 통과 후 reload한다.
2026-11-25 실제 서버에 적용했고, 주요 두 JS 파일은 합계 2,470,398바이트에서 gzip 전송 606,581바이트로 감소했다. 최신 웹 코드는 별도로 app/dist를 배포해야 한다.

## 배포

백엔드 JAR와 app/dist를 모두 갱신한다. DB 스키마 변경은 없다. APK는 별도 재빌드한다.
