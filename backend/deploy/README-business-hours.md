# 음식점·관광시설 운영시간

공공데이터포털의 한국관광공사 국문 관광정보 서비스_GW 활용 신청:
https://www.data.go.kr/data/15101578/openapi.do

EC2의 /etc/ai-trip-planner.env 에 TOUR_API_SERVICE_KEY=인증키 를 등록합니다. 키를 채팅이나 Git에 올리지 마세요. 인코딩 키는 한 번 디코딩하며 일반 키도 지원합니다.

적용 순서: 서비스 중지 → 2026-11-04-business-hours.sql 실행 → 새 JAR 업로드 → 서비스 시작. 운영시간은 새 DB 칼럼을 사용하므로 SQL을 먼저 실행합니다. 환경 변수와 JAR은 프로세스 시작 시 읽으므로 백엔드 재시작이 필요합니다.

Kakao 장소명이 같고, 전체 도로명 주소·건물번호가 일치하거나 좌표가150m 이내인 관광공사 항목 한 개만 연결합니다. 주소의 시·도 정식명/약칭과 괄호 안 동 이름은 정리합니다. 양쪽에 전체 도로명 주소가 있지만 서로 다르면 가까워도 연결하지 않습니다. 시·군·구만 같은 주소는 주소 일치로 인정하지 않습니다. 다른 지점명이나 여러 후보가 겹치는 경우는 연결하지 않습니다. 음식점, 관광지, 문화시설, 레포츠, 쇼핑 유형을 조회합니다.

경로 보정 후 방문 시작부터 60분을 검사합니다. 확인된 휴무·마감·휴게시간과 겹치는 장소는 제외하고 안내합니다. 자동 시간 이동이나 대체 장소 추천은 하지 않습니다. 추가 요청의 필수 장소가 빠지면 기존 요청 검증이 생성을 거절할 수 있습니다.

날짜·데이터가 없거나 계절별 시간, 공휴일 예외 등 해석이 불확실하면 운영시간 미확인으로 남깁니다. 임시휴무·예약·실시간 영업 여부는 보장하지 않습니다. 기존 일정은 재생성해야 데이터가 추가됩니다.

플랜 한 개당 기본 최대40회(Tour 검색+상세 각각1회), 4개 병렬, 최대15초 대기입니다. TOUR_API_MAX_CALLS로 변경할 수 있으며 최대100입니다. 동일 장소는 서버 메모리에24시간, 검색 불일치는6시간 캐시합니다. 조회 실패는 캐시하지 않습니다. 개발계정 할당량을 확인하고 필요하면 한도를 낮추세요. 키 미등록·조회 실패는 생성 전체를 중단하지 않습니다.
